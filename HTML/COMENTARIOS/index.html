Comentários no HTML

Comenários são textos que não são exibidos no navegador, mas que podem ser usados para documentar o código. Geralmente só são vistos por desenvolvedores através dos google dev tools.

O atalho usado para acesso aos comentários é Ctrl + ;. Comentários não podem ser usados durante trabalho, pois, caso o código seja publicado, os comentários podem ser vistos por qualquer pessoa. Isso demonstraria falta de profissionalismo e descuido com o código, podendo prejudicar a imagem do desenvolvedor. Portanto o comentário deve ser usado unicamente para fins de estudo e aprendizado.
